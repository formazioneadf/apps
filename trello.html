Trello JSON → CSV per Excel

Carica un export JSON completo di una bacheca Trello. La conversione avviene esclusivamente nel browser: nessun dato viene inviato online.

Trascina qui l'export JSON di Trello oppure fai clic per selezionarlo

Disattivato per impostazione predefinita, come nel Python originale senza l'opzione --include-archived.

Comportamento mantenuto dal Python
Esporta le informazioni leggibili della bacheca, pulisce le descrizioni email, riconosce la priorità, riassume checklist e allegati, esporta gli assegnatari, individua l'ultimo operatore dalle azioni disponibili nel JSON, converte le date nel fuso Europe/Rome e ordina le schede secondo lista e posizione Trello.
